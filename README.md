# Rent Manager Uganda

A rent management system designed for landlords, property managers, and tenants in Uganda.

## Purpose

Rent Manager Uganda helps landlords and tenants manage rental properties, rent payments, tenants, leases, and property records in one place.

## Planned Features

- Landlord registration and login
- Tenant registration and login
- Property and house management
- Tenant management
- Rent payment recording
- Rent balance tracking
- Rent due-date reminders
- Lease management
- Payment receipts
- Monthly rent reports
- Property occupancy tracking
- Maintenance requests
- Notifications
- Dashboard for landlords
- Tenant dashboard
- Mobile-friendly interface

## Uganda Focus

The system will be designed for the Ugandan rental market and will support Uganda Shillings (UGX).
